# WaveDeck {VERSION} for Android

Install `WaveDeck-{VERSION}-android.apk` on Android 8.0 or later. This is a universal APK for phones, including ARM64 and ARMv7. Android 16 is the primary emulator test target. It is signed with this workspace's persistent **development** key, not a Play Store signing key.

Copy the APK to your development phone, open it in a file manager and allow that file manager to install unknown apps when Android asks. Or, with an explicitly connected and authorized development phone, run `adb -s YOUR_DEVICE_SERIAL install -r WaveDeck-{VERSION}-android.apk`. This build does not install itself on physical devices.

- **Add music** selects local audio through Android's file picker. **Add folder** grants access to a selected music folder; subfolder scanning is configurable. WaveDeck keeps read permission for future launches without requesting access to all files.
- Paste a public YouTube video/playlist or direct audio URL and tap **Go**. Stream, Download and Download & play are available. Playlists can load further pages; chaptered individual videos can add each song separately. Use Android's Share → WaveDeck for YouTube links.
- Playback continues with the screen off or another app open. Use the lock-screen/media notification or wired/Bluetooth media buttons for play/pause, next/previous and seeking. One wired headset-hook click toggles playback, two clicks advance and three go back. Phone firmware and earbud gesture assignments may change which commands are sent.
- Disconnecting an audio route pauses playback. Audio focus handles other media apps and calls through Android. Playback is owned by a media foreground service and is independent of the activity. Force-stopping the app or restarting the phone stops audio; the saved queue/position restores paused for the next explicit Play command.
- **Equalizer / Knobs / Effects** expand the ten-band EQ, preamp/width, tone/compression/balance, independent speed/pitch, echo/reverb/filter/crush/mix controls. A/B bypass preserves volume. Volume is perceptual, matching the desktop curve.
- Background preparation caches the start of up to three upcoming online songs without notifications on failures. Android's player also preloads the next playlist item. Network streams are not guaranteed gapless.
- Long-press a song to save it offline, remove its offline copy, share its URL or remove it from the queue. Offline copies use the original encoded audio in private app storage, shared between chapters of the same source. They remain until removed or the app is uninstalled. They are not exported as converted MP3/FLAC files.
- Settings offer Modern, OldSchool and Retro themes, then Language (English / Português (Brasil)), chapter/scanning options, playlist limits and update checks. Future APK installation requires Android's confirmation and a matching signer; the desktop ZIP updater is not used on Android.

YouTube access depends on the site's responses and network. This build uses anonymous public-video extraction and does not import the desktop Google session or submit watch history. Desktop absolute file paths must be selected again on the phone. Android audio formats depend on the device decoders; source DRM/private/blocked videos are not guaranteed playable. Manufacturer battery restrictions can affect foreground playback; validate on the development phone before treating hardware behavior as confirmed.

Keep `tools/android-signing/` private and backed up. Deleting its key/password prevents creating updates with this development signature. APKs, SDKs, signing material and build output are ignored by Git. Build from source with `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Publish-Android.ps1`; it uses the central `Directory.Build.props` version, runs required checks, verifies the APK signature and writes this folder plus SHA-256 checksums.

The Android APK includes GPL-3.0-or-later NewPipe Extractor; the combined Android distribution follows that license, while WaveDeck's original MIT source and desktop licenses are preserved. Source and dependency notices are included in the source tree and APK assets. Published releases provide the matching Android application and extractor source bundle alongside the APK.
