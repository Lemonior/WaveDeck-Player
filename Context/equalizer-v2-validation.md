# WaveDeck Equalizer V2 validation - 2026-10-04

Delivery: Windows x64, version 1.0.0, `D:\MusicPlayer\WaveDeck\WaveDeck.exe`. New UI is the Windows implementation. The shared Linux project compiles with the processing changes; its existing packaged interface has not been replaced.

## Implemented

- Channel C's Aurora is a mirrored frequency contour, Ribbons is a stereo waveform and Orbit is a radial projection of measured envelope / spectral energy. All coordinates come from the audio or fixed display geometry. No elapsed-time oscillator, synthetic wave or independently advancing color animation is used. Trails are the actual seven preceding frames; a roughly 10 KB ring is reused. Pause / Freeze hold the shape and sound-free frames have no decorative wave. Stereo phase remains selectable. Low volume/mute does not starve visual data; L/R meters still measure output.
- Equalizer tab retains the ten bands, preamp, width and safe gain. Knobs provides bass, presence, air, drive, compression and balance. Effects provides independent tempo/pitch, echo, room, low-pass sweep and bit crushing. Detail adds delay time/feedback, room decay, resonance, wet/dry mix and tape mode. Detailed window is modeless. Every knob supports drag, wheel, keys, fine dragging, reset and exact-value entry.
- Live processing does not reopen the source when controls change. Tempo preserves pitch; pitch preserves speed; tape mode optionally links them. Full A/B neutralizes processing, speed and pitch while retaining the chosen setup. Default resets all tabs and preserves volume. The EQ V2 enable checkbox has been removed; the tabs and global controls share one header row. Each tab's Reset and Presets affect only that tab. The top preset selector and saved full presets apply complete sound setups; legacy EQ presets load with neutral new controls. Safe gain now reacts to actual output peaks rather than subtracting estimated tone boosts from the entire song.
- Generated effects are for playback. Source files and downloaded chapter segments remain intact. Delay and time-stretch buffers reset on seek, tempo flushes at EOF, and chapters retain relative position / paused state. Large echo/reverb/time-stretch buffers allocate lazily. There is no claim of a new measured RAM improvement.

## Listening limits

Numerical tests use generated tones/impulses; Windows integration playback is muted. Real musical listening quality, perceived distortion/reverb character and pitch/tempo artifacts remain interactive checks. This is a player with live sound shaping, not a multi-deck mixing/recording application. No real account session, original music file or user's preferences are modified by the validation runs.
