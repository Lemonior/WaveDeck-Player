# WaveDeck 1.0.0 desktop update validation - 2026-10-04

Windows package: `D:\MusicPlayer\WaveDeck\WaveDeck.exe`. Version stays 1.0.0. Native Windows x64, self-contained .NET 10.0.12. Shared Linux project also builds successfully; these desktop additions have not been ported into the packaged Linux interface.

## Implemented behavior

- Remember the active main track or nested chapter, its relative playback position and chapter shuffle. Restore paused without starting the output device, even when remembering the main queue is disabled. Opening files takes priority. Checkpoint every 15 seconds, on play/pause and before closing; do not serialize the whole queue on every checkpoint. Disabling playback memory clears the checkpoint.
- Native background media play/pause, stop, previous and next, including device buttons that send Windows media commands. Configurable global play/pause defaults to Ctrl+Alt+Space; available choices include Ctrl+Space and Ctrl+Shift+P or Off. RegisterHotKey uses no-repeat and releases registrations on close. Existing local shortcuts and taskbar controls remain.
- Settings can register WaveDeck as a possible default application for supported audio/video and playlist extensions, then open Windows Default apps. Per-user capabilities, quoted command paths, Open with registration, Player multi-selection model and an Explorer folder action are supplied. Do not write Windows UserChoice or force defaults. Registration updates the executable location if the portable folder moves.
- First selected audio starts when opened externally. Subsequent opens forward to one player per profile over a current-user-only named pipe. Sibling discovery defaults on and recursive scans default off; both are configurable. Paths are deduplicated.
- Independent A/B/C switches and original XP-inspired Aurora, Ribbons and Orbit graphics, plus the existing Stereo phase option. Layered trails and color cycling are configurable and remembered. Modes do not change the audio signal.
- Normal web sign-in still delegates to the default browser. A separate temporary sign-in profile uses only its own loopback endpoint; browser cleanup does not close the user's usual profile. Explicit .txt import handles Netscape session exports without accessing a protected browser database. Malformed/expired/unsigned exports are rejected, unrelated domains discarded, and stored sessions encrypted using Windows DPAPI. The selected export file is retained for the user to delete. Login policies can still reject a separate browser window; a real account was not tested.
