Launcher: **D:\MusicPlayer\WaveDeck\WaveDeck.exe**, version **1.2.1.0**. Self-contained Windows x64, .NET 10.0.12. Development launcher: MusicPlayer\MusicPlayer\bin\Debug\net10.0-windows\WaveDeck.exe, also 1.2.1.0.

## Changes verified

- Chapter metadata is checked automatically in the background at each video start, including saved videos and previously empty results. Existing saved song identities and file paths survive metadata refreshes. Optional chapter failures leave playback running.
- The manual Chapters and separate song-repeat buttons are removed. The second sub-control row contains only Song previous, Song next and Song shuffle. Existing Repeat One repeats the current song; main-playlist and song shuffle remain separate.
- Pending downloads no longer prevent playback. Ready files play locally; unfinished downloads can stream independently. Current pause/resume, seek, volume, EQ, repeat/shuffle and Stop work while replacement audio prepares.
- Download progress is coalesced every 150 ms, with bounded UI batches. Late download-and-play completion respects newer manual navigation and Stop. A cancelled/replaced network seek cannot restart stopped audio.

## Limits of verification

The additional fresh public chapter-metadata test was blocked by YouTube's **Sign in to confirm you are not a bot** challenge. Evidence: artifacts/v1.2.1-live-chapters/online-results.json; a second public chapter fixture from yt-dlp's own extractor tests returned the same challenge. Live automatic chapter discovery therefore remains an interactive check. Automatic detection, refresh, pause/position handling and saved-song preservation passed with isolated chapter fixtures. No personal account or browser session was accessed for validation.

Song boundaries require published video chapter metadata. Unlabelled recordings cannot be split reliably. Network resolution and unavailable streams can still delay transitions; these tests establish responsive controls and reduced interruptions, not strictly gapless output or audible-quality approval. Physical mouse feel and account-specific private/member/history access remain interactive checks from the prior release.

The tests used isolated artifact directories and original test audio. Shipped artwork remains original WPF/vector code; reference game screenshots are not bundled.
