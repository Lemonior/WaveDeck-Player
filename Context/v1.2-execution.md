# WaveDeck 1.2 execution — 2026-10-03

Implemented the requested drag hit areas, unclipped knobs, monitor work-area maximizing, vector header icons, centered video-title/WaveDeck header, original Modern/Retro console textures, styled menus/scrollbars/errors, compact playback bindings/ten-second seeking, taskbar thumbnail transport, browser-agnostic shell sign-in, broader site/generic media URLs, quiet audio retry/skip, and optional connected-account YouTube watch requests. Removed the Go explanation from Settings. OldSchool artwork is retained.

Latest chapter clarification is implemented as nested songs inside ONE main queue entry, with a song selector and separate previous/next/repeat/shuffle controls beneath the transport sub-controls. Song time/seek is relative to its source segment. Last-song EOF hands off to the next main playlist entry; playlist repeat-one restarts the album. Prefetch retains both the first song and its parent main entry, including during playlist shuffle. WaveDeck JSON and M3U metadata retain nested songs, boundaries and saved file paths.

Chapter splitting is enabled by default for downloads. The worker discovers chapter metadata, saves individual titled segments via FFmpeg/yt-dlp, registers individual completion tasks, and signals Download & play on the first successful saved song while the others continue. It reuses saved segments by URL/boundaries/encoding/destination. A concurrently finishing download cannot change the source offset of audio that is already playing or being sought.

Sign-in opens a normal HTTPS URL using Windows shell execution, without a named browser/profile. A separate explicit Connect action imports an available supported default-browser session, filters temporary exports to Google/YouTube, encrypts the filtered session with DPAPI and removes the temporary file. Browser protection/profile selection and site restrictions can prevent connection. No real account/profile was accessed in validation. Watch submission is opt-in, after playback, and site-controlled.
