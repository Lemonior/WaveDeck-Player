# WaveDeck 1.0.2 validation - 2026-11-19

Changes: anonymous startup checks against the public GitHub Releases repository, Settings / Check Updates, verified portable update installation with automatic restart and playback-state handoff, and up to three silently prepared upcoming songs on Windows and Linux. The central version is 1.0.2.

Validation:

- Both .NET 10 Release projects compile with zero warnings and errors. Windows and Linux self-contained ZIPs package successfully with matching assembly versions, runtime/tools/licenses, VERSION.txt, per-file update-manifest.json and outer SHA256SUMS.txt.
- Windows native suite: **78/78 checks passed**. Update coverage includes strict stable versions and no downgrade, exact platform assets, anonymous requests, verified streamed downloads, corrupt archives, digest disagreement, unsafe URLs, prerelease exclusion, cancellation, ZIP traversal/duplicates/symlinks/altered files, manifest verification, replacement/obsolete managed-file removal, unrelated-file preservation, backups, rollback after a later conflict or Windows file lock, and single-use resume state.
- Shared lookahead checks cover three-source bounds, chapter-to-playlist transitions, shuffle-history preservation, Repeat One, silent background errors, consuming ready sources and disposing stale resources.
- Focused WPF feature checks pass: three upcoming songs prepare while current audio plays; a missing background file produces no notification attempt or failed-song marker; foreground playback of that same failed file retains retry/skip feedback and moves to the prepared successor. An update snapshot restores the paused song at 4.5 seconds, queue and A/B state even with RememberQueue and RememberPlayback disabled. Update settings and central version render in both languages.
- Focused WPF localization checks pass, including Language placement, both choices, persistence/Cancel, live translated display values and unchanged media metadata. The Portuguese catalog passes unique-key and matching-format-placeholder checks.
- A real isolated Windows helper handoff passed against an extracted 1.0.1 portable installation, supplied with a generated baseline manifest for this controlled test. The staged 1.0.2 helper became ready, left installed files unchanged while its exact parent was alive, waited for ordinary window closure/process exit, installed the update, kept a backup and reopened WaveDeck automatically. Every installed file hash matched the new manifest; the one-use resume snapshot was consumed and the isolated Portuguese/settings flags stayed intact. This does not imply 1.0.1 itself contains an updater: users must install 1.0.2 manually once.
- Evidence is local and ignored under `artifacts/update-validation/`: native/feature/localization results, final and verified reruns, handoff/results.json and controlled fixtures. Release packaging uses separate GUID staging folders; no live installation is overwritten.

Startup checks are quiet on offline/error responses; manual checks show a recoverable message and release-page option. Downloads and imports must finish before the app initiates its handoff. Failed preference writes prevent handoff. The file transaction retains changed originals under `.wavedeck-backups`; ordinary failures roll back, while power loss or a failure of rollback itself is not claimed to be recoverable automatically.

Linux compilation and archive validation pass; native Linux desktop/update execution was not available on this Windows host because the registered WSL distribution's disk is missing. Checks do not establish audible listening quality, real Google sign-in/history, restricted streams, gapless network playback or behavior on other machines. Automatic restart is required to activate new compiled player code; the application reopens itself and restores the snapshot.
