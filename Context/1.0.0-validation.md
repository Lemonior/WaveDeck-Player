Launchers:

- Windows: **D:\MusicPlayer\WaveDeck\WaveDeck.exe**, version 1.0.0.0. Debug launcher also 1.0.0.0.
- Linux x86_64: **D:\MusicPlayer\WaveDeck-Linux\WaveDeck**, assembly version 1.0.0.0. Copy the complete folder to Linux, run `bash install-dependencies.sh` if dependencies are missing, then `bash launch.sh`.

Both builds include .NET 10.0.12. Windows keeps WPF/NAudio output; Linux uses Avalonia 12.1.3/SDL2. Shared code covers playlist/storage/paging/shuffle, URL import/resolution/downloads, chapter metadata/cutting, FFmpeg decode, audio analysis and EQ.

## Memory results

The Windows visualizers now reuse sample arrays and FFT workspace, cache Hann coefficients and themed drawing resources, refresh more slowly while idle, and skip visualization rendering while minimized. Theme revisions clear drawing caches correctly even when the same theme is reapplied. Runtime GC memory conservation is enabled. No periodic forced GC, working-set trimming, arbitrary heap cap or smaller network audio buffer is used.

Matched sequential benchmark: muted original stereo WAV, Modern theme, one queue entry, 7-second phase warm-up and 25 one-second samples per phase. Original 1.2.1 versus optimized 1.0.0 on this workstation. No personal player settings were used. Private memory is process private committed memory; working set includes shared runtime/rendering pages and is a different measurement from Task Manager's default private working set.

| Phase | Before private MB | After private MB | Before working-set MB | After working-set MB |
| --- | ---: | ---: | ---: | ---: |
| Initial idle | 113.18 | 120.83 | 145.34 | 156.30 |
| Playing | 118.78 | 101.22 | 154.00 | 157.47 |
| Minimized | 118.88 | 104.50 | 153.81 | 161.05 |

Playback private memory fell **14.8% (17.56 MB)**. Total working set remained similar, and initial idle memory increased. These figures do not establish a universal total-RAM reduction. Results vary with rendering, framework pages, queue length, codecs and workload. The small first comparison was within noise; the longer comparison is reported here. Evidence: artifacts/memory-before-long/memory.json, artifacts/memory-after-long/memory.json and artifacts/memory-comparison-1.0.0.json. scripts/Measure-Memory.ps1 reproduces the workload.

The native allocation regression verifies reusable snapshots retain the same arrays and FFT values with less than 30 KB allocated across 100 refreshes, including assertions. The former implementation created three sample/spectrum arrays and an FFT array on each refresh. Download/UI responsiveness and the existing decoder buffering remain covered by regressions.

## Linux scope and platform limits

Linux includes local media, URL streaming/downloads, automatic nested chapters, separate chapter downloads, responsive playback controls, all three textured themes, preferences, browser-agnostic sign-in/explicit session connection, optional history requests, large playlists and application shortcuts. SDL2, FFmpeg/ffprobe, ICU/OpenSSL, font/display libraries and xdg-utils are installed through the host package manager. The helper supports Debian/Ubuntu, Fedora and Arch package managers; only the recorded Ubuntu environment was executed here.

This package targets glibc Linux x86_64 with X11/XWayland and a desktop audio session. ARM, musl and native Wayland-only environments require additional targets. The first Linux interface uses a roughly 970x980 logical minimum window. Windows taskbar/media features remain intact; Linux MPRIS/global media-key integration is not yet implemented. Session files on Linux use owner-only permissions, not Windows DPAPI encryption. Browser protection and account restrictions may prevent connection; chapter discovery requires available published metadata. Network failures can still delay transitions; strictly gapless output is not claimed.

Primary platform references: [Avalonia supported platforms](https://docs.avaloniaui.net/docs/supported-platforms), [SDL queued audio](https://wiki.libsdl.org/SDL2/SDL_QueueAudio), [SDL audio format](https://wiki.libsdl.org/SDL2/SDL_AudioSpec).
