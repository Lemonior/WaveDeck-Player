# WaveDeck 1.1.1 validation — 2026-10-03

Main launcher: `D:\MusicPlayer\WaveDeck\WaveDeck.exe`, version 1.1.1.0. Includes its Windows .NET 10.0.12 runtime and existing audio tools. Saved preferences, Google session and remembered library remain unchanged by the update.

## Browser fix

Windows default HTTPS association is queried using `AssocQueryStringW`, with a registry registration fallback. A supported default is selected ahead of installed fallback browsers; registration arguments and the regular browser profile are not reused. This workstation selected **Brave**, with `IsDefault: true`, and launched a fresh headless Brave profile successfully. Synthetic Google/YouTube session capture, encryption, domain filtering and profile cleanup passed. No real account cookies, passwords or existing browser profiles were accessed by these tests.

Unsupported/unavailable default browsers receive an explicit compatible-browser fallback message. Real Google sign-in remains an interactive user check. Brave, Chrome, Edge, Vivaldi and registered Chromium/Opera executables are recognized.

## OldSchool redesign

The target is the user's current brown RuneScape 3 lobby/settings screenshots, supported by the March 2026 brown settings-ribbon reference. The old blue interface is not the design target. All shipped artwork is original WPF code.

OldSchool now uses near-black brown textured surfaces, subtle stone facets in the header, matte controls, double gold frames with corner highlights, warm serif headings, gold row outlines, golden scrollbars and a bright gold play control. The original orange/brown chrome gradient is removed from this theme. Palettes are cached for the live visualizers. Modern and Retro retain their palettes and chrome; fantasy frames, textures and scrollbar templates are conditional on OldSchool, and theme transitions restore the other styles.
